# Filobulus

Mining mod for Hypixel Skyblock. Fabric, Minecraft 26.3.

Work in progress.

# Disclaimer
I used AI when building this project, I know alot of people are really not fond of AI so if that's not your thing I just wanted to leave a disclaimer here.
I'm also not very proud of these tools but it does help me develop things so much faster. 

## Build

Needs JDK 25.

```
./gradlew build
```

If you just want the mod check the releases tab and that's it, you can do /filobulus to configure the mod settings and check the features.
